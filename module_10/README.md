# Module 10: Diamond Price Analysis Dashboard

## Research Question
**Can the price of a diamond be determined based upon its features?**

This dashboard explores the relationships between diamond characteristics (carat weight, cut quality, color grade, clarity, and dimensions) and market price to determine which features are most predictive of value.

## Data Source
- **Dataset**: Diamonds dataset from [Kaggle](https://www.kaggle.com/datasets/shivam2503/diamonds)
- **Size**: 53,940 diamond observations
- **Variables**: Carat, cut, color, clarity, depth, table, price, and dimensions (x, y, z)
- **Why this dataset**: It is clean, well-structured, and contains clear relationships between features and price, making it ideal for exploratory visualization.
