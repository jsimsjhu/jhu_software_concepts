About This Project

What is this?

This is a class project for JHU Software Concepts. It uses a fine-tuned transformer model (DistilBERT) to predict graduate admissions outcomes based on self-reported GradCafe data.

How does it work?

The model combines text fields (program name, comments) with structured fields (GPA, GRE, degree, citizenship) into a unified text input, then fine-tunes a pretrained language model for binary classification (Accepted vs Rejected).

Disclaimer

This model is trained on scraped, self-reported data from GradCafe. It is not a real admissions decision tool. The predictions are for educational purposes only and should not be used for actual admissions decisions.
